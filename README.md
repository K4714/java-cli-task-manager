A simple command-line task manager built in Java.

## Features
- Add tasks
- List tasks
- Mark tasks as complete
- Delete tasks

## How to Run

1. Compile:
   javac Main.java

2. Run:
   java Main

## Example

--- Task Manager ---
1. Add task
2. List tasks
3. Complete task
4. Delete task
5. Exit
